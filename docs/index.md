# 横浜国立大学 教科書レビュー

講義で使う教科書・参考書の情報や、学生のレビューを共有するサイトです。授業名や教授名から教科書を探し、実際に使った学生の評価や感想を確認できます。

## 教科書レビューサイトの使い方

### 教科書を探す

1. 「教科書一覧」から、学科・学年で絞り込むか、授業名・教授名・教科書名で検索します。
2. 授業の項目を開くと、指定教科書と市販参考書の情報を確認できます。
3. 教科書名の下で、わかりやすさ・授業での使用頻度の評価や、レビューを確認できます。

### 教科書情報を登録する

1. 「教科書を追加」タブを開き、学科・学年を候補から選択します。
2. 授業名・教授名を入力または登録済み候補から選びます。指定教科書と市販参考書は任意です。
3. 教科書が入力されている場合は、わかりやすさや授業での使用頻度も評価できます。
4. 「追加する」をクリックして登録します。同じ授業名・教授名の情報は既存の登録に統合されます。

### レビューや評価を投稿する

教科書一覧で対象の授業を開き、各教科書の「レビューを見る・投稿する」からレビューを投稿できます。レビューには、授業で使う頻度や教科書のわかりやすさなど、ほかの学生の参考になる情報を記入してください。評価やレビューは、対応する教科書ごとに表示されます。

## レビューサイトを開く

レビュー機能を使うには、Streamlitアプリの公開が必要です。まだ公開されていない場合は、次のリンクからStreamlit Community Cloudでこのリポジトリをデプロイしてください。

[Streamlit Cloudでアプリをデプロイする](https://share.streamlit.io/deploy?repository=ToaruMK/streamlit-practice&branch=main&mainModule=app.py)

デプロイ時はリポジトリ `ToaruMK/streamlit-practice`、ブランチ `main`、メインファイル `app.py` を指定します。公開後は、発行されたStreamlitアプリのURLからレビューサイトを利用できます。

> GitHub Pagesは案内ページを公開する場所です。レビュー投稿・評価機能はGitHub Pages上では動作せず、Streamlitアプリ上で動作します。
